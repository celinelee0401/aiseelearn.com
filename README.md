# AI See Learn

Static GitHub Pages prototype for AI See Learn.

Domain: `aiseelearn.com`

## Current Scope

- Frontend-only prototype.
- No server-side login.
- No student answer database.
- Unit 1 Dialogue Task Check flow for classroom testing.
- Local browser resume is enabled through `localStorage`.

## Suggested GitHub Pages Settings

Publish from the repository root on the `main` branch.

Required files:

- `index.html`
- `unit1-dialogue-task-check.html`
- `CNAME`
- `.nojekyll`
- `assets/`

## Future Expansion

- Student accounts
- Cloud learning history
- Teacher dashboard
