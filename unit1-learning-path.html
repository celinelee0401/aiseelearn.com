B3 U1 7 節課安排

這是預設播放清單，不是鎖死的課表。每一節都可以依班級狀況壓縮、延後、改紙本或指定回家。

Before Period 1

Vocabulary Preview

單字互動自學網先作為回家作業，讓學生在進 Dialogue 前有第一輪接觸。

  • Homework單字卡、搭配詞、看英選中、中英配對、聽英拼寫。
  • Evidence完成度、總分、弱單字、拼字與搭配詞錯誤。
Homework Required Prep Dashboard later
Period 1

Dialogue Core

用圖片線索進入 Dialogue，完成聽力表格並開始 Dialogue Check。

  • 3-5m老師設定任務：listen for people, places, weather, things。
  • 5-7mTask 1 Step 1 See-Think-Wonder。
  • 12-18mTask 1 Step 2 video + Listening Table。
  • 8-12mTask 2 Dialogue Check 開始，只顯示推薦支架卡。
Required Online Evidence high
Open Dialogue
Period 2

Dialogue Output

完成理解檢查，做短延伸，並穿插第一次單字提取練習。

  • 5-10mVocabulary Quiz 1，紙本或線上短測。
  • 12-18mTask 2 finish：Word Rescue / Match / Retell / Why。
  • 8-12mTask 3 short version：Same Summer, Different Weather。
  • 5-8m老師統整 clue、evidence、because。
Required Paper/Online Flexible Extension
Period 3

Dialogue Fluency / Review

讓熟悉語言變得可說、可背、可修正，接到文法前的整理。

  • 8-12mTask 4 speaking / read-aloud / pair read。
  • 5-8mTask 5 short review，可改成回家或 fast finisher。
  • 5-8mOnline Translation Check 1。
  • 10-15mPaper Check 1 或錯誤修正。
Fluency Translation Paper
Period 4

Grammar Bridge

從 Dialogue 例句看見文法，經老師講解後做 guided practice 與小翻譯。

  • 5-8m從 Dialogue 抽例句，學生先 notice。
  • 12-18mTeacher mini lesson。
  • 10-15mGuided practice：填空、改寫、造句或訂正。
  • 5-8mOnline Translation Check 2。
Required Teacher-led Grammar
Period 5

Reading Core

Reading 不固定成單一策略；本節只選一個會考型閱讀能力來練深。

  • 3-5m連結 Dialogue 概念到 Reading 主題。
  • 15-20mReading Task 1：課本 Reading 的一個閱讀焦點。
  • 10-15mReading Task 2：一題 CAP-style evidence practice。
  • 5-8m分享線索，老師命名 reading move。
Required Reading Evidence CAP-style
Period 6

Reading Output / Fluency

把閱讀理解轉成短輸出，並補第二次單字提取與第三次翻譯檢查。

  • 5-10mVocabulary Quiz 2。
  • 8-12mReading Task 3：opinion / share with reason。
  • 8-12mReading Task 4：selected paragraph read-aloud or summary。
  • 5-8mOnline Translation Check 3。
Required Output Vocabulary Quiz
Period 7

Unit Wrap / Accuracy Check

收束 Reading strategy、最後一次翻譯檢查，並用紙本或修正循環決定下次支援。

  • 5-8mReading Task 5 exit ticket：說出一個 clue 或 reading move。
  • 5-8mOnline Translation Check 4。
  • 10-15mPaper Check 2。
  • 10-15mPaper Check 3 或 correction / reteach cycle。
Required Wrap Support Regrouping
